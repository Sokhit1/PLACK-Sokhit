# Air Transport Planning and Management

Course materials by **Dr. PLACK Sokhit**, Lecturer in Transport Engineering at the Institute of Technology of Cambodia (ITC), for undergraduate and master's students.

## For students

**[Open the course materials →](https://github.com/Sokhit1/PLACK-Sokhit/tree/air-transport-planning/air-transport-planning)**

Lecture slides, worked examples, classroom exercises and review quizzes for all eight modules:

| Module | Topic |
|---|---|
| 1 | Introduction to Air Transport Systems |
| 2 | Air Transport Demand and Forecasting |
| 3 | Airport Planning and Master Planning |
| 4 | Airport Capacity and Level of Service |
| 5 | Airline Planning and Management |
| 6 | Airline Operations and Financial Performance |
| 7 | Airport Management, Safety and Security |
| 8 | Sustainable Aviation and Future Air Transport |

## Run the ITC Learning Hub locally

Requires [Node.js](https://nodejs.org/).

```bash
npm install
cp .env.example .env.local   # then set APP_URL and any keys you need
npm run dev                  # opens on http://localhost:3000
```

Build for deployment with `npm run build`; the output is in `dist/`.
